# Reference comparison methodology

The project compares Universal with three non-official procedural controls:

- `MultiCam-style`: muted tan, olive, brown, and dark neutral palette;
- `MTP-style`: a related muted multi-terrain palette;
- `Vegetata-style`: a generic Italian woodland palette with stronger greens.

The controls are generated by [generate_reference_baselines.py](../scripts/generate_reference_baselines.py)
and evaluated by the same [evaluate_camo.py](../evaluate_camo.py) pipeline,
using the same environmental backgrounds, 25% uniform height, spread
placement, and sky/water avoidance.

They are intentionally approximate. MultiCam is a proprietary commercial
pattern family, while MTP is the British Army's Multi-Terrain Pattern. The
repository does not include official artwork, logos, or fabric scans. The
British Army describes MTP as a pattern intended for woodland, jungle,
compounds, crops, grassland, and arid stone; that broad design goal is why it
is a useful conceptual control, not because this repository reproduces it.
See the [British Army personal clothing overview](https://www.army.mod.uk/learn-and-explore/equipment/personal-equipment/personal-clothing/)
and [Crye Precision's MultiCam material](https://www.cryeprecision.com/Resources/en/SpecSheets/NLC067_SPEC.pdf)
for external context. These links are references only; the project does not
copy their artwork or claim affiliation.

The generated numerical report is in
`output/reference_comparison/reference_comparison.md`. Treat the values as
relative diagnostic comparisons, not product claims.
