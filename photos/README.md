# Reference photos

This folder is reserved for private local input photographs and is not part of
the public dataset. Before publishing any image, record its source, author,
license, and permission in `photos/SOURCES.md`. Do not assume that a photograph
found online is safe to redistribute just because it can be downloaded.

If the provenance of an image is unknown, keep it local and remove it from the
public commit. The generator can still use local-only photos for experiments.
